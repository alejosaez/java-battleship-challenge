# Battleship — Java Technical Challenge

A console-based implementation of the classic Battleship game,
developed in Java as part of my continued practice and reinforcement
of Java fundamentals and Object-Oriented Programming concepts.

## Features

- 10x10 game board
- Ship placement and validation
- Ship collision detection
- Coordinate validation
- Fog of war
- Hit and miss detection
- Ship sinking detection
- Win condition
- Two-player gameplay

## Concepts Practiced

- Object-Oriented Programming
- Classes and methods
- Arrays and multidimensional arrays
- Encapsulation
- Control flow
- Input validation
- Method decomposition
- State management

## Tech Stack

- Java 17

## Purpose

This repository is part of my Java technical challenges collection.
The goal is to reinforce core Java and OOP concepts through practical
implementations and progressively more complex exercises.
